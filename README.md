## 这个仓库是什么

一个《钢铁雄心 IV》1.19 的**纯脚本 MOD** 仓库，内容是一棵完整的爱尔兰国策树「翡翠岛的抉择」。

- 无 DLL、无 DLC 依赖
- **不含任何自定义美术资源**，全部沿用原版
- 212 国策 / 175 精神 / 95 决议 / 103 事件 / 18 观点修正
- 六条路线：A 新世界爱尔兰（民主扩张）、B 史实自由邦（中立自保）、R 红色革命、X 黑色新秩序、M 共通军事、E 经济

| 目录 | 说明 |
|---|---|
| `mods/ire_the_emerald_isle/` | MOD 源码 |
| `mods/ire_the_emerald_isle.mod` | 启动器识别文件（版本号要跟 `descriptor.mod` 一起改） |
| `AGENTS.md` | **最高优先级规范**，改代码前必读 |

## 快速安装

### 方式一：发布包（推荐）

1. 从 [GitHub Releases](https://github.com/YueWen2005/english-ireland-rework/releases/latest) 下载最新 zip
2. 解压到 `C:\Users\<用户名>\Documents\Paradox Interactive\Hearts of Iron IV\mod\`
3. 启动器 → 播放集 → 勾选「翡翠岛的抉择 - 爱尔兰国策树」

解压后的目录应该是：

```
mod\
├── ire_the_emerald_isle.mod
└── ire_the_emerald_isle\
```

> 如果解压工具自动多套了一层同名文件夹，要把里面的内容手动移到 `mod\` 根目录，否则启动器扫描不到。

### 方式二：手动装（想改脚本时）

把 `mods/ire_the_emerald_isle.mod` 和整个 `mods/ire_the_emerald_isle/` 复制到上面的 `mod\` 目录。

## 已知限制

**动态国名只做了 cosmetic tag，没做完整国名体系**。Éire / 凯尔特联邦 / 爱尔兰共和国 / 爱尔兰-纽芬兰联邦这些国名变化通过 `set_cosmetic_tag` 实现，没有覆盖 `common/country_tags/`（那需要整份替换约 1.5 MB，必然与其他 MOD 冲突）。

**state ID 需要按你的游戏版本核对**。脚本假设北爱尔兰是 119、纽芬兰是 331、伦斯特是 113。如果地图 MOD 有偏移，进游戏用 `tdebug` 悬停省份看 State ID，然后改：

- `common/scripted_effects/IRE_effects.txt`
- `common/decisions/IRE_decisions.txt`
- `common/national_focus/IRE_focus.txt`

**1939 剧本未做专门适配**。开局设定只覆盖 1936，1939 会沿用 1936 状态。这是已知且可接受的（团队不玩 1939 剧本）。

其余引擎限制（特殊建筑、渔农产品资源、精英师模板修正等）见 `mods/ire_the_emerald_isle/README_爱尔兰MOD.md`。
