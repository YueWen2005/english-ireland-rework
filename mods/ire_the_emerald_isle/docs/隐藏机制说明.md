# 隐藏机制说明（给玩家的说明书）

本 MOD 有几个「看不见的数值」：游戏界面不直接显示，只通过国策/事件/决议的 tooltip 提示增减。
这份文件解释它们是什么、怎么涨、有什么用。

---

## 一、红色团结（红线专属）

> 界面提示写作「红色团结 +N」，走红色路线（完成国策《红色转折》）后启用。

**它是什么**：红色爱尔兰内部的团结度计数器，范围 **0～100**（上限可通过国策提到 **110**）。
它**不直接提供任何加成**，而是决定红线后期能不能走通某些关键步骤。

**怎么涨**：
| 来源 | 数值 |
|---|---|
| 国策《红色转折》（上台） | +10 |
| 国策《康诺利纵队》（声援西班牙） | +10 |
| 国策《共和大会》 | +15 |
| 国策《1941 年的分裂》 | +5 |
| 国策《中立劳工运动》 | +10（同时把上限提到 110） |
| 国策《国有化大潮》 | +10 |
| 决议《工人读报班》（工人组织类，可重复） | 每次 +5（花 50 政治点） |
| 各类事件选项 | −10 ～ +15 不等 |

**有什么用**：
- **高于 50**：解锁国策《贝尔法斯特罢工》（北爱斗争路线的入口）。
- **40～70 之间**：每月有 15% 概率触发「宗派危机」事件（一次性），考验你的选择。
- **上限 100 → 110**：完成《中立劳工运动》后，读报班可以多堆 10 点。

**注意**：一些妥协选项会扣团结（如《十字架与红旗》向教会低头 −10）。团结值掉了只能靠读报班慢慢补，红线后期卡门槛会很疼。

## 二、暴露度（黑线专属）

> 界面提示写作「暴露度 +N」，走黑色路线（IRA 军事委员会内战线）后启用。

**它是什么**：IRA 地下活动的「被英国情报机关盯上的程度」，范围 **0～100**。

**怎么涨**：
- 黑线期间**每月固定 +5**（地下战争越拖越危险）。
- 走私军火、黑市工厂、技术窃取等决议各 +3～+5。
- 部分激进事件选项 +5～+20。

**怎么降**：
- 部分谨慎路线的决议/事件可以减（如「收敛行动」类选项 −30）。
- 但多数来钱来装备的操作都会加——**收益和风险是绑定的**。

**有什么用**：
- **高于 50**：触发警告事件（英国情报已经摸到你门口了）。
- **高于 90**：触发「清洗」危机事件——处理不好会引爆内战。
- 暴露度永远不会超过 100，但拖得越久越接近摊牌。

**一句话攻略**：黑线是和英国情报部门赛跑。想要装备和工厂就得吃暴露度，吃多了就要在摊牌前主动降温。

## 三、其他隐藏数值一览

| 数值 | 范围 | 路线 | 作用 |
|---|---|---|---|
| 公投支持度（IRE_plebiscite_support） | 0–100 | 边境公投线 | 决定公投结局：≥90 英国和平移交六郡；70–89 移交但遭制裁；<70 公投失败 |
| 侨民网络（IRE_diaspora_network） | 0–100 | A 线跨海路线 | 20/40/60/80/100 五档解锁「跨海网络」精神 |
| 民族主义支持（IRE_nf_support） | 0–100 | 公投线 | ≥80 时公投必然通过（对应事件选项会变） |
| 中立信誉（IRE_neutral_credibility） | 0–100 | 中立路线 | 影响中立相关事件与外交选项 |
| 开发计数（ Munster/Leinster/Connaught/Ulster 等） | 计数 | A 线 | 统计地区开发决议次数，用于阶段解锁 |

> 以上数值均不会在界面显示，增减只出现在 tooltip 里（「红色团结 +5」「暴露度 +10」等）。

## 四、吞并与殖民（v2.13.0 新规）

- **吞并大英**：其本土核心领土会自动成为爱尔兰核心，大英将领全部并入爱尔兰军队。
- **非洲殖民地**：吞并大英后，英属非洲殖民地（非核心州）独立为「英属非洲」；法国投降/消亡后，法属非洲殖民地独立为「法属非洲」。
- **解放线（红线世界革命分支）**：15 个解放国策必须**按顺序**逐个完成：为了巴黎 → 低地与莱茵 → 伊比利亚之春 → 亚平宁的火 → 多瑙河联邦 → 巴尔干黎明 → 从易北到维斯瓦 → 北方的姊妹 → 印度宣言 → 非洲之年 → 南洋远征 → 中东的石油 → 枫叶旗之下 → 华尔街丧钟 → 拉美回声。
